# RI / CT — Winter field guide

A personal Providence and Hartford guide for December 9–14, 2026.

[Open the guide](https://itscarly.github.io/rict/)

Static HTML, CSS and JavaScript; deploy from main / root with GitHub Pages. Prices and operating details are research estimates checked November 18, 2026; confirm near departure. Booking codes and private contact information are excluded.

## Spending and daytime neighborhoods

`#budget` separates six-day food, souvenirs, local buses and a taxi reserve, with adjustable amounts saved in the current browser. Lodging and already-booked flights/Amtrak are excluded. `#explore` covers student-adjacent Providence neighborhoods, Hartford café/food-hall stops and diner alternatives. Customer ages and future crowds are not measured or guaranteed; meal and taxi amounts are planning allowances. Linked venue/operator sources were checked November 18, 2026.

Run `node export-guide.cjs` to regenerate the self-contained `printable.html` after content changes. Its new sections and current itinerary are included automatically.
